# Bika — B2B платформа заказов

Bika соединяет **покупателей** (магазины, HoReCa) напрямую с **дистрибьюторами**.
Покупатели заказывают в пару кликов, дистрибьюторы обрабатывают заказы,
администратор полностью управляет платформой. Bika запоминает привычки
покупателя и подсказывает, что заказать («умный шогирт»).

## Стек

| Слой | Технология |
|---|---|
| Приложение | Next.js 16 (App Router) + TypeScript — фронтенд и API в одном сервисе |
| Стили | Tailwind CSS v4, мобильный-first дизайн |
| База данных | PostgreSQL + Prisma ORM |
| Аутентификация | JWT (httpOnly cookie), логин + пароль, роли: ADMIN / DISTRIBUTOR / BUYER |
| Хостинг | Railway (один web-сервис + Postgres) |

## Роли

- **Админ** — создаёт пользователей с паролями, управляет товарами/категориями,
  видит все заказы, аналитику, журнал активности, экспорт CSV. Сброс пароля — только через админа.
- **Дистрибьютор** — свои товары (CRUD, категории, остатки, фото по ссылке),
  входящие заказы со сменой статуса (Новый → Подтверждён → Отправлен → Доставлен),
  список покупателей, отчёт по продажам, экспорт CSV.
- **Покупатель** — каталог с поиском/фильтрами, корзина → заказ (адрес + комментарий),
  история заказов, «Подсказки Bika»: часто заказываемое, напоминание о прошлом заказе,
  рекомендации после 3+ заказов и прогресс обучения (n/10).

Корзина с товарами нескольких дистрибьюторов автоматически разбивается
на отдельные заказы — по одному каждому дистрибьютору.

## Запуск локально

```bash
npm install
cp .env.example .env        # заполните DATABASE_URL и JWT_SECRET
npx prisma migrate dev      # создать таблицы
npx prisma db seed          # демо-данные и аккаунты
npm run dev
```

Демо-аккаунты после сида:

| Роль | Логин | Пароль |
|---|---|---|
| Админ | `admin` | `admin123` |
| Дистрибьютор | `tashkent-foods` | `dist123` |
| Дистрибьютор | `milkline` | `dist123` |
| Покупатель | `magazin-baraka` | `buyer123` |
| Покупатель | `cafe-sharq` | `buyer123` |

## Деплой на Railway

1. Создайте проект в Railway и добавьте **PostgreSQL**.
2. Добавьте **web-сервис из этого репозитория**. Railway сам определит Next.js.
3. В переменных web-сервиса задайте:
   - `DATABASE_URL` — ссылка на Postgres (Railway → Variables → Reference).
   - `JWT_SECRET` — случайная строка (`openssl rand -hex 32`).
4. Первая инициализация базы (один раз, из Railway shell или локально с prod `DATABASE_URL`):
   ```bash
   npx prisma migrate deploy
   npx prisma db seed        # по желанию — демо-данные
   ```
5. После деплоя смените пароль администратора.

`postinstall` уже запускает `prisma generate`, скрипт `start` слушает `$PORT`.

## Тесты

Сквозной smoke-тест (нужен запущенный сервер на :3000):

```bash
node tests/smoke.mjs
```

Тест проходит весь бизнес-процесс: логин всех ролей, изоляция доступа, заказ
покупателя со сплитом по дистрибьюторам, смена статусов дистрибьютором,
рекомендации Bika после 3 заказов, создание пользователя админом, CSV-экспорт,
журнал активности.

## Структура

```
app/
  login/            вход
  admin/            панель администратора
  distributor/      портал дистрибьютора
  shop/             приложение покупателя (моб. навигация)
  api/              route handlers (auth, users, products, orders, export)
components/         общие UI-компоненты (карточки, таблицы, корзина, формы)
lib/                Prisma, auth (JWT), форматирование, валидация
prisma/             схема, миграции, сид
tests/smoke.mjs     e2e smoke-тест (Playwright)
```
